# IToDo — менеджер задач (Fullstack)

Fullstack-приложение для управления задачами с JWT-аутентификацией и асинхронной работой с PostgreSQL.

🔗 Онлайн-версия: https://itodo.itouch.pw

---

## 🛠 Стек

### Бэкенд

- FastAPI
- PostgreSQL
- SQLAlchemy (async)
- AsyncPG
- Alembic
- JWT (access / refresh)
- bcrypt

### Фронтенд

- React
- React Router
- Axios
- JavaScript

### Инфраструктура

- Docker
- Docker Compose

---

## 🧠 Архитектура

Слоистая структура backend-приложения:

routes → services → dao → database

### Принятые решения

- Разделение API, бизнес-логики и слоя доступа к данным
- Асинхронная работа с базой данных (SQLAlchemy + asyncpg)
- DTO через Pydantic для изоляции моделей БД
- JWT-аутентификация (access / refresh токены)
- Миграции базы данных через Alembic
- Контейнеризация и воспроизводимое окружение через Docker

---

## ⚙️ Решённые задачи

- Реализация access/refresh токенов

## 📊 Объём проекта

---

## 🚀 Запуск

```bash
docker-compose up --build
```

Проект демонстрирует реализацию fullstack CRUD-приложения с продуманной архитектурой, асинхронной работой с БД и контейнеризацией.
