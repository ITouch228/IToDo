# IToDo — менеджер задач (Fullstack)

Fullstack-приложение для управления задачами с JWT-аутентификацией и асинхронной работой с PostgreSQL.

---

## 🛠 Стек

### Бэкенд

- FastAPI
- PostgreSQL
- SQLAlchemy (async)
- AsyncPG
- Alembic
- JWT
- bcrypt

### Фронтенд

- React
- React Router
- Axios

### Инфраструктура

- Docker
- Docker Compose

---

## 🧠 Архитектура

Слоистая структура:

routes → services → dao → database

### Принятые решения

- Разделение бизнес-логики и API
- Асинхронная работа с базой данных
- DTO через Pydantic
- JWT-аутентификация
- Миграции базы данных через Alembic
- Контейнеризация

---

## ⚙️ Решённые задачи

- Реализация access/refresh токенов
- Защита маршрутов
- Изоляция данных пользователя
- Асинхронные транзакции
- Настройка CORS

---

## 📊 Объём проекта

- 15+ REST endpoint
- Полный CRUD-цикл
- Асинхронная ORM
- Разделение слоёв приложения

---

## 🚀 Запуск

```bash
docker-compose up --build
```

Проект демонстрирует реализацию fullstack CRUD-приложения с продуманной архитектурой.
